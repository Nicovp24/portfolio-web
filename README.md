# Nicolás Vicenti - Portfolio

A modern, responsive portfolio website showcasing my work as a Full Stack & Automation Developer. Built with vanilla HTML, CSS, and JavaScript, featuring smooth animations and a clean design.

## 🚀 Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Smooth Animations**: CSS transitions and JavaScript-powered effects
- **Typewriter Effect**: Dynamic text animation on the hero section
- **Scroll Snap**: Smooth section navigation with scroll snapping
- **Interactive Elements**: Hover effects and micro-interactions
- **Accessibility**: Proper ARIA labels and semantic HTML
- **Performance Optimized**: Lightweight and fast-loading

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Custom properties, flexbox, grid, and animations
- **JavaScript (ES6+)**: DOM manipulation and interactivity
- **Google Fonts**: Inter font family for typography

## 📋 Sections

1. **Hero**: Introduction with animated rings and typewriter effect
2. **About**: Background and current learning goals
3. **Experience**: Professional work history with technology badges
4. **Skills**: Technical skills organized by category
5. **Projects**: Featured projects with descriptions and tags
6. **Contact**: Contact form and social links

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs entirely in the browser

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nicovp24/portfolio-web.git
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio-web
   ```

3. Open `index.html` in your web browser:
   - Double-click the file, or
   - Use a local server (recommended for better performance):
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve .
     ```

4. Visit `http://localhost:8000` (if using a server) or open the file directly.

## 📱 Usage

- **Navigation**: Use the scroll wheel or arrow keys to navigate between sections
- **Home Button**: Click the home icon to return to the top
- **Social Links**: Click the icons in the navigation to visit my profiles
- **Contact**: Use the contact form or email link to get in touch

## 🎨 Customization

The design uses CSS custom properties (variables) for easy theming:

- `--color-bg`: Background color
- `--color-teal`: Primary accent color
- `--color-ink`: Text color
- `--color-white`: White color

Modify these in the `:root` selector in `index.html` to change the color scheme.
